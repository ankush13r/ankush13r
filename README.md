# Hi, I'm Ankush 👋

**Research Engineer II at the [Barcelona Supercomputing Center](https://www.bsc.es/)**, in the Language Technologies unit.
I work on **post-training of open multilingual LLMs**: fine-tuning, reinforcement learning and agentic tool use.

## 🔬 What I work on

- **Reinforcement learning for LLMs** — multi-node RL post-training (GRPO / GSPO) with NeMo-RL and Megatron on the MareNostrum 5 supercomputer: reward design, LLM judges, environment servers.
- **Verifiable environments for AI agents** — training environments over real multilingual data (Wikipedia in Catalan, Spanish and English, open-data portals, scientific papers, office apps) where answers can be checked automatically, including when the right answer is "it isn't there".
- **Fine-tuning data at scale** — pipelines for function-calling and reasoning data: quality filtering, multilingual reasoning traces, chat templates.
- **Agentic evaluation** — reproducible function-calling and multi-turn agent benchmarks (BFCL, tau2-bench, Inspect) on HPC.

## 🧠 Models

Contributor to the open **[ALIA / Salamandra](https://huggingface.co/BSC-LT)** model family (BSC-LT on Hugging Face): function calling, post-training and evaluation.
